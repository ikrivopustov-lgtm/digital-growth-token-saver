# Делегирование

## Когда субагенты экономят, а когда жгут

Субагент — отдельный тред: он заново читает AGENTS.md, схемы инструментов и свои файлы,
а корень всё это время живёт и перечитывает свой контекст на каждом ответе.
Замер автора `codex-astra-luna-orchestrator` (один баг, ~6k строк, 4 субагента):
корень съел ~4.8M токенов (в основном кэш), вся задача — 66% пятичасового окна Plus.
То есть оркестрация **дороже** одиночной работы, если задача не большая.

Экономия появляется, только если дешёвая модель забирает объёмное чтение/рутину,
которое иначе делала бы дорогая модель в своём контексте.

| Ситуация | Делать |
|---|---|
| tiny / routine | сам, без субагентов |
| нужно прочитать 20+ файлов, чтобы найти 3 места | `explorer` (read-only, короткий отчёт) |
| 2+ независимых куска в разных файлах | `worker` на каждый, с явным владением файлами |
| рискованный дифф (auth, миграции, деньги) | `reviewer` после реализации |
| проверка версии API/библиотеки | `researcher` |
| рутина, не связанная с текущим контекстом | `delegate.sh` |

## Контракт делегирования (обязателен)

Objective · Scope (файлы) · Constraints (что не трогать) · Deliverable · Acceptance.
Субагент возвращает выводы, пути, команды и результаты — не сырые логи и не файлы целиком.

## delegate.sh

```bash
bash ~/.codex/token-saver/delegate.sh "найди все места, где читается ENV API_KEY, верни список file:line"
bash ~/.codex/token-saver/delegate.sh -w "добавь docstring во все публичные функции src/utils/*.py"
bash ~/.codex/token-saver/delegate.sh -p impl -w "выполни задачу 3 из .ai-factory/PLAN.md"
```

- По умолчанию `-p fast` и `--sandbox read-only`; `-w` даёт запись в рабочую папку.
- Вложенные субагенты запрещены (`agents.max_depth=0`).
- Ответ пишется в `.codex/delegate/<время>.md`, в консоль — только его путь и итог.
- После запуска скрипт читает rollout и печатает, **какая модель реально отработала**.
  Если модель не та — в выводе будет `MODEL MISMATCH`.

## Баг Codex App (#32587)

В Codex App `spawn_agent` может игнорировать `model` из `.codex/agents/*.toml` и запускать
детей на модели родителя. В CLI (0.153.x) роли работают. Поэтому:
- в App для рутины надёжнее `delegate.sh`;
- после любой сессии с субагентами: `token_usage.py --latest` и смотри колонку Model.
